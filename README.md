# Random Quote Generator

A simple Python application that displays random inspirational quotes.

## Features

- Stores 10 inspirational quotes and their authors
- Randomly selects a quote each time the program runs
- Displays the quote with its author
- Uses Python's built-in random module

## Requirements

- Python 3

## Installation

1. Clone the repository.
2. Navigate to the project directory.
3. Create a virtual environment:

   python3 -m venv venv

4. Activate the virtual environment:

   source venv/bin/activate

5. Install dependencies:

   python3 -m pip install -r requirements.txt

## Usage

Run the application:

python3 main.py

## Project Structure

- main.py - Main application
- requirements.txt - Project dependencies
- .gitignore - Files excluded from Git
- README.md - Project documentation

## Testing

The virtual environment can be deleted and recreated using the installation instructions above.

The application should run successfully after recreating the environment.
